# SideNote Pro - Markdown Scratchpad & Web Sticky Notes

> Contextual domain-smart Markdown scratchpad for Google Chrome. Pin notes, code snippets, and research checklists to any website. 100% on-device.

## Features
- **Domain Memory:** Automatically saves and displays notes specific to the active website.
- **Global Scratchpad:** Fast access to a universal vault for general snippets and thoughts.
- **Right-Click Snippet Capture:** Highlight text on any page and click "Save selection to SideNote" to clip with source link and timestamp.
- **Markdown & Live Preview:** Full GFM support (headings, bold, italics, checklists, code blocks, blockquotes).
- **1-Click .md Export:** Download your notes as clean Markdown files.
- **Privacy Guaranteed:** 100% on-device offline storage via `chrome.storage.local`.

## Installation
1. Clone or download this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this directory.
